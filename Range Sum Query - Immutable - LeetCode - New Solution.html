Intuition

Recomputing the sum from left to right for every query is O(N) per
query. Instead, precompute a prefix sum array once so every range query
becomes a simple O(1) subtraction.

Approach

  1. Build prefixSum of size n+1 where prefixSum[0] = 0.
  2. Fill it as prefixSum[i] = prefixSum[i-1] + nums[i-1].
  3. For any range query [left, right]:
    sum = prefixSum[right+1] - prefixSum[left]

Why n+1 size?
The extra slot at index 0 acts as a sentinel — eliminates the need to
special-case queries starting at index 0.

Why does the formula work?

prefixSum[right+1] = sum of nums[0..right]
prefixSum[left]    = sum of nums[0..left-1]
difference         = sum of nums[left..right] ✅

class NumArray {
public:
    vector<int> prefixSum;

    NumArray(vector<int>& nums) {
        prefixSum.resize(nums.size() + 1, 0);
        for (int i = 1; i <= (int)nums.size(); i++)
            prefixSum[i] = prefixSum[i - 1] + nums[i - 1];
    }

    int sumRange(int left, int right) {
        return prefixSum[right + 1] - prefixSum[left];
    }
};
